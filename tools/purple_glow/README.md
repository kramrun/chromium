# Purple Glow

Локальный прототип расширения Chromium MV3. Чтобы загрузить: откройте `chrome://extensions`, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите эту папку. После загрузки нажмите значок расширения. Ничего не активируется автоматически.

Выберите цвет и режим движения, затем нажмите «Включить на этой вкладке». В сложной странице подходящих областей может не быть. При изменении DOM, прокрутке или изменении размеров окна эффект отключается. Из-за сложной верстки и изменений через CSS стопроцентно гарантировать отсутствие пересечений невозможно. Страницы браузера и магазин расширений недоступны для изменения.

Кнопка «Открыть страницу с часами» открывает `newtab.html` как страницу расширения. Также можно открыть `chrome-extension://ID_РАСШИРЕНИЯ/newtab.html`, подставив идентификатор из `chrome://extensions`. Страница новой вкладки браузера не переопределяется. Поиск обращается к Google только после явной отправки запроса; до этого страница не выполняет сетевых запросов. Цвет и режим хранятся локально и применяются к этой странице автоматически. Системное уменьшение движения учитывается.
