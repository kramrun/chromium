# Purple Glow: пользовательский CSS сайтов

Локальный прототип расширения Chromium MV3. В `chrome://extensions` можно включить режим разработчика и загрузить эту папку как распакованное расширение. Самостоятельно оно не включается. Ничего не устанавливается автоматически и новая вкладка браузера не переопределяется.

В меню расширения выберите цвет и анимацию декоративного эффекта. После нажатия кнопки он действует только на подходящие пустые декоративные области текущей страницы; при прокрутке, изменении DOM или размера окна отключается. Подходящие области существуют не на каждом сайте. Сложная верстка может приводить к неожиданному результату.

«CSS текущего сайта» — отдельная функция для изменения веб-страницы, а не интерфейса браузера. CSS сохраняется локально отдельно для каждого точного origin (протокол, домен, порт). Сохранение само по себе ничего не применяет: необходимо нажать «Применить сейчас». При переключении вкладок стиль сохраняется на открытом документе. При перезагрузке или переходе на другой документ стиль удаляется и автоматически не применяется; его нужно включить заново. При изменении адреса внутри текущего документа, например при переходах внутри SPA, стиль остаётся активным. Выключение удаляет только созданный расширением стиль. Удаление сохранённого текста не выключает уже применённый стиль — для этого есть отдельная кнопка.

Можно использовать обычный CSS, включая `@import` и `url()`: **такой CSS может загружать ресурсы из сети, менять или скрывать текст, формы и видео**. Не вставляйте непонятный или недоверенный код. Это ввод стилей, пользовательский JavaScript расширение не исполняет. Политика сайта может заблокировать встроенный стиль; встроенные фреймы и закрытый Shadow DOM могут не измениться. Установка и видимый результат на конкретных сайтах пока не проверены.

Кнопка «Открыть страницу с часами» открывает страницу расширения; также можно открыть `chrome-extension://ID_РАСШИРЕНИЯ/newtab.html`, подставив идентификатор из `chrome://extensions`. Поиск на ней обращается к Google только после отправки запроса; до этого страница не выполняет сетевых запросов. Цвет и режим хранятся локально. Системное уменьшение движения учитывается.
