# Quiet Violet — пример темы Chromium

Тема меняет цвета интерфейса браузера и страницы новой вкладки. Она не изменяет сайты, не содержит JavaScript и не добавляет прозрачность или анимацию. Цвета можно настроить, изменив RGB-значения в `quiet_violet/manifest.json`.

Как установить тему:

1. Скачайте папку `quiet_violet` вместе с файлом `manifest.json`.
2. Откройте `chrome://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку `quiet_violet`.
4. Чтобы вернуть стандартное оформление, откройте `chrome://settings/appearance` и сбросьте тему.

В режиме инкогнито, при использовании системной темы и высокой контрастности цвета могут отличаться. После изменения цветов проверьте читаемость текста и элементов интерфейса.

Тема загружена в установленном Chromium 154 с отдельным временным профилем: браузер сохранил её как активную. Внешний вид не проверялся. Изменённый форк Chromium пока не собирался и с этой темой не проверялся.
