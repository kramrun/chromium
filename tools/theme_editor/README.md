# Мастер тем Chromium

Откройте `index.html` в браузере. Это самостоятельный локальный редактор цветовой темы с приблизительным предпросмотром; его не нужно собирать, он не обращается к интернету. Это не встроенный раздел настроек Chromium.

1. Выберите цвета и название, нажмите «Скачать manifest.json».
2. Создайте отдельную папку и поместите в неё скачанный файл `manifest.json`.
3. В Chromium откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите эту папку.
4. Чтобы вернуть стандартную тему, откройте `chrome://settings/appearance`.

Можно открыть существующий `manifest.json` темы и изменить поддерживаемые цвета. Импортируются только шесть перечисленных в редакторе цветов и имя; изображения, другие цвета и остальные свойства не сохраняются при экспорте. Некоторые режимы, темы ОС и версия Chromium могут изменять реальный результат. Это инструмент для цветов интерфейса, он не оформляет сайты и не добавляет прозрачность или анимацию.
